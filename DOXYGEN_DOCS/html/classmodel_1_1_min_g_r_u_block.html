220# ── Transformer (RoPE + GQA + SwiGLU + Attention-Sink Sliding-Window)
221#
222# Three targeted fixes over the vanilla version:
223#
224# 1. **No train/test mismatch** – windowed causal attention is used
225# during training too (when the sequence is longer than the window),
226# so the model never learns to rely on context it won't have during
227# streaming. The first ``n_sink`` positions are always visible to
228# every query (attention sinks).
229#
230# 2. **SwiGLU FFN** – gated feed-forward (Shazeer 2020, used by LLaMA /
231# Mistral / DeepSeek) gives better parameter efficiency than the
232# plain GELU FFN.
233#
234# 3. **Grouped-Query Attention (GQA)** – shares KV heads across
235# multiple query heads (Ainslie et al. 2023), shrinking the KV
236# cache by ``n_heads / n_kv_heads`` and freeing capacity.
237#
238# Streaming: KV cache keeps the first ``n_sink`` tokens plus a sliding
239# window of the most recent ``window_size`` tokens, bounding memory to
240# O(n_sink + window_size) per layer — same as before but now matched to
241# training.
242#
243# References
244# Xiao et al., "Efficient Streaming Language Models with Attention
245# Sinks", 2023.
246# Ainslie et al., "GQA: Training Generalized Multi-Query Transformer
247# Models from Multi-Head Checkpoints", 2023.
248# Shazeer, "GLU Variants Improve Transformer", 2020.
249# ──────────────────────────────────────────────────────────────────
