Detailed Description

Context-manager wrapper around CPPJoules EnergyTracker.

Usage::

    tracker = EnergyTracker()
    tracker.start()
    # ... do work ...
    tracker.stop()
    results = tracker.results()   # dict[str, float]

Or as a context manager::

    with EnergyTracker() as t:
        # ... do work ...
    print(t.results())
