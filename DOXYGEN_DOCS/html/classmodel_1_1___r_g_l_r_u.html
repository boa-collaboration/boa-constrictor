Detailed Description

Real-Gated Linear Recurrent Unit — diagonal SSM with input-
dependent gating.

Recurrence:
    λ_t = exp(−softplus(ν) · σ(a(x_t)))       per-dim decay
    h_t = λ_t ⊙ h_{t-1} + (1 − λ_t) ⊙ gate(x_t) ⊙ proj(x_t)
