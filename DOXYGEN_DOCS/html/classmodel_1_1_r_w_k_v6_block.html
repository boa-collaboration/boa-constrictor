699# ── RWKV-7 "Goose" (Peng et al., 2025) ─────────────────────────
700#
701# Extends RWKV-6 with a *non-diagonal* state transition matrix,
702# enabling cross-dimension state interactions (beyond TC⁰).
703#
704# State update (per head):
705# S_t = (diag(w_t) + a_t b_t^T) · S_{t-1} + k_t v_t^T
706# o_t = S_t @ r_t
707#
708# The rank-1 term a_t b_t^T lets the model perform "copy"
709# state transitions and recognize all regular languages.
710#
711# Uses FLA Triton kernels on CUDA, sequential fallback on CPU.
